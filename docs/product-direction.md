# 手绘风产品文档

更新：2026-10-28。本文确定下一轮改版方向，不代表功能已全部实现。

## 1. 产品定位

**AI 视觉创作实战社区。**

用户在这里看作品、找方法、做内容、交流经验。支持手绘、漫画、海报与写实摄影等多种视觉风格。

核心价值：**好看的作品，能复用的方法，真实的创作交流。**

## 2. 用户与任务

| 用户当前的需要 | 产品提供什么 |
| --- | --- |
| 找灵感、试效果 | 作品浏览、画风与图型、快速创作 |
| 持续制作内容 | 参考图、连续组图、批量生成、文章配图 |
| 解决问题、分享经验 | 实测案例、求助讨论、失败复盘、做法分享 |

同一用户可以在不同任务间切换。

## 3. 产品主线

**看作品 → 查看做法 → 换主题创作 → 保存结果 → 自愿分享。**

提供两条创作路径，共用资源、收藏与历史：

- **快速开始**：选择画风或图型，输入主题、数量和比例，直接生成，无需手工连线。
- **深入创作**：进入画布，组合参考与参数，制作组图、批量任务和可复用工作流。

用户也可以从资源编号或搜索结果直接开始。

## 4. 页面与功能

主导航：**发现、画风与图型、创作台、社区**。账号菜单提供收藏、历史和个人设置。

| 页面 | 核心要求 |
| --- | --- |
| 首页 | 先展示真实作品与做法，再提供用途入口、新资源和近期讨论。榜单与奖励作为次要信息。 |
| 画风与图型 | 支持按编号、名称和用途查找；展示预览、说明、作者、来源与使用权限；可收藏并带入创作。 |
| 作品详情 | 看清成图，找到关联资源；展示作者已公开的提示词、模型、参考与调整过程；提供查看做法和复用入口。 |
| 创作台 | 清楚显示已选参数、主题、数量、比例及费用；生成后可查看、下载、重试或主动分享。保留高级画布。 |
| 社区 | 支持晒作品、求改进、分享提示词、工具经验、失败复盘和发布经验。作品、资源与讨论相互关联。 |
| 个人空间 | 管理自己的作品、收藏、生成历史与工作流；支持本地 Skill 个人库同步。 |
| 管理后台 | 按角色处理内容、举报、资源与账号；管理入口不占用普通用户的主要页面。 |

首页按“公众号配图、小红书组图、漫画绘本、海报”等任务组织入口。内容不足时减少栏目，不用示例数据填充。

## 5. 网站调性

**专业、实用、开放、有趣。**

- 视觉：保留暖纸、墨色与朱砂，减少装饰、徽章和密集说明，让作品占据主要空间。
- 语言：说清能做什么、怎么做。使用“看作品”“查看做法”“开始创作”等直接表达。
- 氛围：欢迎尝试、提问和失败复盘，容纳兴趣创作与商业实践。
- 反馈：突出作者署名、感谢、收藏和真实复用；减少奖励与曝光权重的重复展示。

首页文案：

> 看看大家做出了什么，也把你的做法留下来。
>
> 浏览画风、图型和真实作品，找到适合这次创作的方法。

主要操作：**发现作品、开始创作。**

## 6. 产品规则

- 公开内容可供访客浏览；生成、收藏与投稿按账号权限使用。
- 投稿以标题、文字和图片为主，资源可直接分享描述或提示词，不要求 ZIP。
- 运行前展示免费额度、本批预计消耗和收费项；区分资源解锁与生成费用。
- 用户主动运行才提交生成任务；重复点击不重复扣费。等待、失败和退款状态以服务端确认为准。
- 生成历史、参考素材与未发布内容默认私有；用户主动发布后，才公开所选内容。
- 作品配图与做法对应，引用标明来源；互动数按记录计算，冷启动与自然增长分开统计。保留旧资源、解锁资格、账本与已有链接。
- 图片按需加载，延续现有加载限速与错误重试规则；不能为提前加载大量图片拖慢浏览。

## 7. 本轮范围

1. **首页与资源发现**：调整内容顺序，突出作品、做法和用途，统一主要入口与文案。
2. **创作入口**：完善快速开始，提前展示额度和费用，保留高级工作流与草稿。
3. **复现与分享**：检查作品、资源、创作台和讨论之间的关联，补齐保存与主动分享的衔接。

视频生成、真实支付、新的付费规则和旧站迁移分别立项。本轮保留现有能力与权益，不扩展这些范围。

## 8. 验收

- 新用户能看懂网站用途，从作品找到做法，并开始一次创作。
- 熟练用户能搜索编号、复用参考、批量制作并恢复自己的历史与工作流。
- 点击运行前能看清数量、额度和预计费用；任务状态与实际结果一致。
- 桌面和手机都能清楚浏览图片、使用主要操作；登录、收藏与保存有明确反馈。
- 内容发布范围明确，真实内容环境没有测试账号、验收作品与模拟互动。

## 9. 冷启动

使用原创虚构账号准备首批多样内容，前台按普通用户展示。用户名、人物设定与帖子重新创作，不复制微信群成员及原话。后台保留冷启动标记，单独统计，支持批量管理；互动数由实际记录计算，不用固定补值。内容覆盖创作练习、方法分享、提问、失败复盘与日常讨论。

上线后观察：从浏览到创作的转化、首次生成完成率、失败恢复率、保存率与主动分享率。先建立基线，再设目标。
