# 当前产品约束（2026-10-21）

## 分享与资源

普通投稿只需要标题、文字与图片。画风和图型直接分享描述或提示词，读者收藏、复制并使用，不要求制作、上传或解压 ZIP。使用许可可以补充填写。

新投稿不申请依赖 ZIP 附件的积分下载。原有附件、解锁资格和账本保留兼容，不在界面中继续鼓励上传附件。后续若设计付费画风，应以结构化定义和鉴权使用为核心，另行定义发布与解锁规则。

## 在线生图

用户确认线上已部署 GPT 号池。已检查服务器存在 chatgpt2api 服务，具有图片生成和异步任务接口；主站目前尚未接入该鉴权接口。此前“只能拼提示词，必须在外部工具出图”的产品边界已过时。

目标流程：选择画风、图型和配色 → 输入主题 → 在线生成 → 保存结果 → 主动分享到社区。复制提示词仍作为可选操作。

接入使用主站服务端调用，保留现有登录与用户权限；不向浏览器暴露号池密钥，不把号池管理后台作为公开创作台。需要任务去重、用户额度、排队、低频状态查询、失败反馈及用户私有的生成历史。用户主动点击前不消耗生图额度，不自动把生成图片发布到社区。

目前仅确认服务和接口代码存在、健康页可响应；没有发起收费或消耗配额的生成测试，未声称主站在线生图已经接通。

## 图片加载

- 图片和画廊使用 static/img 静态分发，避免请求论坛动态服务。
- 列表图片在接近视口时才进入加载队列，同时最多两张，每次新请求间隔至少 600ms。
- 图片错误后暂停队列十秒，不连续切换备用域名或地址；用户可主动重试。
- 弹窗大图在用户打开时加载，隐藏分类和未滚动到的图片不预加载。
- 此限制只作用于门户和本仓库构建的画廊；论坛正文图片仍遵循 Discourse 自身加载策略。

这些是保守初始值，不表示已掌握 CDN 的实际限流阈值。后续依据真实请求量、错误率和首屏速度调整。
