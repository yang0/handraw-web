# 论坛资源详情与关联列表

状态：本地已完成，未生产部署。主评审负责决策、集成和验收，DeepSeek 提出实现。验收见 [forum-resource-review-20261029.md](forum-resource-review-20261029.md)。

## 目标

画风、图型、作品的详情统一进入论坛。采用同一论坛外壳和三种资源模板，保留结构化记录及原资源 ID，不把定义、价格和关联关系复制进正文。

## 页面

- 资源详情：`/forum/?view=resource&kind=style|layout|work&id=...`。
- 关联列表：`/forum/?view=related&kind=...&id=...&tab=...`。
- 画风：示例、定义、使用入口；关联作品、搭配图型、相关讨论。
- 图型：版式、结构说明、使用入口；关联作品、搭配画风、相关讨论。
- 作品：完整成图、创作说明、公开做法、复刻入口；关联画风、图型、相关讨论。
- 详情最多展示每类 4 项关联预览及「查看全部」；完整列表独立分页加载，提供搜索、排序和准确总数。
- 图片优先、中文名称、暖纸与朱砂、桌面和手机可用；沿用图片加载队列。

## 规则

1. 每个资源有唯一详情地址，绑定原论坛主题；一帖多资源可以切换资源，继续共用同一讨论，不能复制评论。
2. 普通帖子仅附带资源卡片时，仍是普通帖子，不能误判为资源主帖。
3. 官方零评论资源可直接查看；浏览详情不创建公开帖或评论。首条公开评论后才进入论坛列表；全部评论隐藏后移出列表。
4. 画风与图型的搭配来自已发布作品的实际使用组合，不按标题猜测。关联列表排除未收录、已下架和正常模式的演示数据。
5. 待收录内容只展示公开预览，禁止使用或复刻；修改审核期间，已收录旧版继续生效。
6. 保留解锁、版本、作者和管理权限。付费定义、付费提示词和黑盒秘密不得通过详情、关联列表或搜索泄露。
7. 收藏、点赞和使用针对具体资源，讨论引用原主题；不存在第二套同内容收藏和评论。
8. 旧资源详情、作品详情和已有分享链接继续可用，并进入新论坛详情；原目录、作品浏览和创作台继续使用。
9. 不新增常驻后端服务；不提交、推送或生产部署；保留当前未提交的其他工作。

## 实施与验收

1. 独立资源详情、关联列表和评论分页 API；复用现有权限、评论和资源序列化规则，不用整站 boot 组装关联列表。
2. 三种详情模板、独立关联列表、原帖上下文和一帖多资源导航。
3. 接入论坛路由，迁移目录、作品卡片、分享与旧链接。
4. 隔离数据库测试匿名、本人、他人、管理员、锁定、解锁、待收录和隐藏；验证实际关系、去重、分页、共用评论与无评论不入列表。
5. 浏览器完成三类详情、关联列表、普通帖、旧链接、登录后评论及手机宽度验收，再备份并更新本地单服务。
