# 资源链接带入修复

状态：本地 3080 已更新。

问题：`/studio/?entry=quick&style=FA-001` 误用预置海报工作流。预置图带默认画风、图型、主题和海报模式，而表单不接受该模式，因此显示不可用提示。此前双模式修复只覆盖模式按钮，没有覆盖 URL 初始化。

修复：资源链接复用已有的干净图构造函数，带入指定且类型正确的画风、图型；采用表单支持的图文模式，主题留空。支持编号前后空白、井号和小写。无效编号显示提示，不替换成旧草稿里的资源；同链接里有效的另一项仍保留。已有草稿与画布标签保留。

DeepSeek 提供修复提案，主评审整合并修正混合有效/无效资源及空参数处理。

验证：新增 `tests/test_studio_resource_entry.cjs` 使用真实引擎构造器和 URL 初始化，覆盖首次进入、有历史草稿、画风、图型、组合、编号规范化、无效编号、错误类型、空参数、画布入口和作品复刻。该检查及原产品、创作台状态、资源展示、导航检查均通过。

浏览器使用用户原链接确认表单显示、FA-001 已选、图型与主题为空；从画风详情点击使用按钮得到同一结果。IG-001 图型链接已验证，表单与画布互切后仍保留该图型。未执行生图。
