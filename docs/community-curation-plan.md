# 投稿、收录与社群审核验收清单

## 必须完成
1. 画风、图型、作品一次分享先产生论坛帖；每项独立待收录，只有收录通过才进入公共目录/作品列表并可被选择和复刻。允许一帖包含多项，普通讨论保持原流程。
2. 投稿者可见状态/审核记录/退回理由，可修改重提；关键定义新版本重新审核，旧已收录版本继续可追溯；作者可申诉，管理员处理。
3. 管理员可批量按 style/layout/work 授予、暂停和恢复审核资格；至少一项同类内容被收录后自动有同类资格；不变更用户全局角色，不给后台其他权限。
4. 系统分配待审内容，不允许任何人自审；两人意见一致通过或退回，分歧增加第三人按多数决；重复操作幂等，旧版本票无效，暂停资格后不能投票；管理员可补位，处理申诉留理由和记录。
5. 官方画风/图型始终可评论，0公开评论不进入论坛；首条有效公开评论自动产生唯一讨论入口；资源页/论坛共用评论，不复制两份；全部公开评论隐藏后入口隐藏，新评论恢复原入口；待审评论不触发；活动排序不改资源上架时间。
6. 既有资源/作品/权益/链接保留；新投稿不能绕过收录进入目录/生成/Skill同步；图片归属和私有媒体公开规则保留；不伪造互动，不重复发奖励。
7. 桌面/手机、普通作者/合格审核者/管理员均可完成各自流程；新页面保持中文图片选择与单端口导航。
8. 隔离DB自动测试和浏览器真实完整流程；不生产部署、不上传私有群聊或凭据。

## 使用规则

- 管理员在「社区 → 审核资格管理」多选用户和类型，批量授予、暂停、恢复；用户全局角色不变。
- 画风、图型、作品分别计算资格。同类至少一项已上架收录内容即可获得资格，暂停优先于自动资格。
- 既有正式上架内容按历史收录处理；演示记录、虚构冷启动账号不自动获得资格。
- 审核者只处理系统分配给自己的任务，24 小时未完成释放名额。两票一致决定，分歧时补第三票。
- 作者通过「我的投稿」修改重提、查看历史和申诉。新版本通过前保留原已收录版本；奖励只在首次收录发放。
- 官方资源评论与论坛共用原评论记录；新投稿评论以原论坛回复为准。一帖多项投稿共用该帖讨论。
- 创作台跨页面预填使用本人私有草稿，30 分钟过期；最后点击发布才公开选中的图片。
