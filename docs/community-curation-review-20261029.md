- 57 项隔离后端测试通过，包括普通用户、匿名、其他所有者、管理员、付费内容、图片归属、CSRF、并发任务分配和投票重放。

- 浏览器验证图片文件上传、图片画风选择、作品投稿先进入论坛、作者修改重提、旧版仍可用、版本历史、退回后页面表单申诉和管理员留理由复核。
- 浏览器验证资源详情评论进入原论坛；官方画风 0 评论不入论坛，首条评论创建讨论。自动测试补充全隐藏后消失、后续评论恢复同一讨论、两处治理操作修改同一记录。
- 1440 像素桌面与 390 像素手机布局已检查。图片加载沿用现有队列。

## 评审修正

- 暂停记录与人工授予标记分离，恢复暂停不会额外赋权。
- 分配名额同时计入活跃任务与已投票用户；过期、暂停、冻结与旧版本任务会释放。
- 付费定义不进入公开投稿预览；完整材料只供本人、被分配审核者和管理员查看。
- 旧直接发布、后台新建社区资源、收录资源定义直改及未收录资源生成入口不能绕过审核。
- 评论无复制存储，修复详情页删除和论坛隐藏操作的评论来源识别。
- 自动资源讨论没有伪造的官方作者主页；原生申诉输入框改为页面内表单。
- 保留首次收录、开荒和荣誉晋升奖励，后续版本不重复发放。
