# 论坛资源详情验收

日期：2026-10-29。状态：本地完成，未提交、推送或生产部署。

## 产品结论

采用一个论坛外壳、三种资源详情。资源记录负责定义、价格、版本和使用关系，原论坛主题负责讨论。用户从资源找到做法，也能从讨论进入资源使用。

- 画风展示示例与定义，关联作品和搭配图型。
- 图型展示预览与结构说明，关联作品和搭配画风。
- 作品展示完整成图与做法，关联实际使用的画风和图型。
- 详情每类最多预览 4 项；独立关联列表提供搜索、排序和每页 24 项的分页。零数量分类隐藏。
- 一帖多资源可以切换，评论共用原存储、原 ID。普通帖子附带资源卡片时继续使用普通模板。
- 官方资源零评论时可查看，浏览不创建论坛主题；有公开评论才进入论坛流，公开评论清空后退出。

## 实施评审

DeepSeek 提供了两轮前后端代码提案。主评审整合页面，并替换未通过评审的全量关联查询，修正资源定位、评论权限、登录回跳、真实收藏与点赞反馈、举报入口及旧链接。

新增 `backend/forum_resources.py`、`backend/forum_resource_routes.py` 和 `demo/assets/forum-resources.js/css`。旧的独立资源详情模板改为跳转，目录、作品列表、创作台继续使用原入口。没有增加数据库迁移。

关联作品、讨论和评论使用 SQL 计数与分页。画风与图型搭配由已发布作品聚合；仅聚合后的资源编号与数量用于合并静态库和社区库。列表不返回定义或提示词。

付费提示词与定义在锁定时不返回，黑盒秘密不返回。未收录内容只展示公开预览；修改审核期间保留已收录版本。隐藏记录不会回退到同编号静态资源。隐藏讨论不返回正文与评论。
