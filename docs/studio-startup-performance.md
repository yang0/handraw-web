# 创作台启动性能（#252）

创作台现在先提供可操作的单图/画布界面，再恢复云端文章摘要和在途任务；参考图库在首次打开参考图选择器时加载。文章入口仍等待同步基线，避免把未加载的云端文档当作新文档保存。

## 改动

- 创作台脚本使用 `defer`，保持依赖执行顺序，同时下载；提前请求目录、选项和主脚本。
- 公开 JS/CSS/SVG 与已去掉定义的公开目录/选项支持 gzip、ETag 和按编码区分的条件请求。编码缓存有容量上限，源码文件改变后重新计算。带版本的源码缓存一小时；无版本源码必须重新验证。API 和私人媒体不使用此公开缓存。
- `/api/boot?surface=studio` 保留会话、人民币/积分/额度、资源目录与权限、个人收藏及管理能力，跳过社区帖子/回复/作品、公共统计、讨论装载和全站资源社交聚合。普通页面仍使用完整启动接口；旧 `forkTopic` 链接保留完整启动数据。
- 初次共享状态通知不再发起随后被取消的重复工作区请求。生成配置与共享启动并行；单图/画布不等待文章列表全部翻页，后台恢复完成后保留当前输入。
- 参考图库请求按账号复用，失败可重试；账号切换后的迟到响应不会填入新账号。

## 本机测量

Chrome CDP 9221，同一隔离 PostgreSQL、非演示账号、120 篇文章。浏览器模拟 80ms 延迟，下载 1.5MB/s，上传 0.75MB/s，未降低 CPU 速度。冷加载清空浏览器缓存，热加载启用缓存。计时终点为单图输入框或画布节点就绪，不将这个指标称为 LCP。

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| 单图冷加载 | 3.75 秒 | 1.89 秒 |
| 画布冷加载 | 3.46 秒 | 1.52 秒 |
| 单图热加载 | 3.43 秒 | 0.31 秒 |
| 画布热加载 | 2.96 秒 | 0.28 秒 |
| 冷加载传输量 | 约 2.47MB | 约 0.61MB |
| 首次工作区请求 | 2 次，其中 1 次被取消 | 1 次，在后台恢复 |

这些是指定本机与网络条件下的前后对比，线上时延还取决于代理、设备、数据量及缓存状态。原始瀑布数据位于忽略目录 `.local/issue-252-browser/baseline.json` 和 `prioritized.json`。画风/图型同样获得公开静态文件压缩缓存，但创作台独有的初始化改动不改变其完整页面数据。

## 验收

- CDP 在 1440/820/390 宽度检查单图、文章和画布，无页面横向溢出；输入保留、参考图库按需打开、120 篇文章分页恢复、文章保存刷新、已保存画布恢复及历史打开均通过。
- 43 项后端专项通过，覆盖精简启动状态、访客隔离、资源权限矩阵、gzip/304/禁用编码、源码缓存失效、目录不含定义、私人 API 不公开缓存、工作区查询及历史边界。
- 17 项启动与通用页面浏览器/后端检查通过，包含刻意阻塞工作区接口时首屏仍可输入、恢复后输入不丢失。
- 38 个 CI JavaScript 脚本通过；生成/文档隔离/同步/历史专项 37 项通过，包含参考图库的跨账号迟到响应及失败重试。
- 无数据库结构变更，无付费图片调用，未部署或修改业务数据库。远端最终 CI 结果记录在 #252。
