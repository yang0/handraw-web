# 完整创作台

视觉：沿用纸张底色、墨色文字与朱红操作色，左侧编排选项，右侧突出生成结果和任务状态。
内容：六类创作模式，主题与场景、画风与图型、比例与情绪、影调与参考图、逐张批量计划、实际提示词与 Skill 指令。
交互：选项即刻更新指令，服务端解析实际提示词；完整图片预览，明确显示等待、运行、完成与错误状态，尊重减少动态效果的设置。

`ops/refresh_studio.py` 从公开 Skill 导入原始指令拼装函数、比例、摄影类型、情绪、影调、官方角色及模型画风策略。不读取个人资源库。网站中的社区定义由服务端检查解锁资格后解析。

保留纯图、图文、海报、文章插图、文章封面、摄影、三档留白、自由比例、多选情绪和影调、写实与双画风融合、随机组合、角色／道具／场景、照片转绘、批量与混合图型、中英文指令、复制和重置。文章模式可粘贴正文或导入 TXT／Markdown；本机路径仍可作为 Skill 指令复制，在线服务不假装能读取用户电脑文件。

在线生成只接受结构化选项，重新解析保护定义；预览和生成使用同一个解析器。私人参考图逐次检查归属，号池通过异步编辑接口接收图片字节，密钥不进入前端。每批最多五张，一次事务预占额度，串行执行，未知状态不启动下一张；取消仅撤销尚未提交的任务，重复取消不重复归还。历史任务及已预占额度不因页面刷新或跨日丢失。

生成仍使用同一号池、不扣社区积分、不新增现金交易。上传及生成结果默认私有，用户主动分享后才发布成图；上传参考图不会自动成为公开附件。
