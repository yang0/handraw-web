# 文章编辑器统一验收

2026-10-29。具体源码与测试修改由 DeepSeek 提出，主评审检查、应用并验收。

- 文章名称、新建、文章目录与旧详情链接统一使用一个编辑器。目录仅保留“打开文章”。
- 正文始终可编辑；排版预览是同页可展开区域，移除独立编写/预览模式切换。
- 配图卡片、提示词编辑、规划、生图、导出和发布在同一工作台内操作。规划后仍停留在编辑器。
- 普通保存不重新构建卡片；明确重新规划保留匹配的图片、卡片 ID 与自定义提示词。
- 新稿使用独立 ID；快速切换先保存，旧定时器和离开页面监听受账号与当前编辑器保护。
- 目录地址统一，刷新后仍显示目录。
