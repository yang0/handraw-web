# 画风、图型与四类内容交易

探索的核心对象为画风和图型，官方与社区使用相同的详情和创作流程。作品和经验可关联两个不同画风、一个图型；关系保留来源版本与角色，不产生自动解锁或额外分账。

## 发布与访问

新投稿只有 work、experience、style、layout 四类。公共摘要和私有内容分别存储，完整内容位于 `handraw_contents`，不写入 Discourse 的 raw、cooked、历史、搜索、邮件或 RSS。正文图片存放在私有目录并逐次鉴权，不能通过静态域名取得。

作品须有图片和实际提示词；经验在论坛的“写经验／分享经验”入口编辑试读和完整正文。现有论坛帖可收录并增加受保护的进阶内容，原来公开过的部分保持公开；测试帖不自动转换收费或追溯奖励。

作品与经验通过基础检查即可交易。画风／图型可免费发布，收费须独立版主审核。默认要求画风三个、图型两个不同主题及图片的复用示例。审核复用资格不自动设置精选；定义更新后重新审核，已有解锁记录仍保留，审核后可免费取得新版本。

## 定价与积分

- 默认免费。作品／经验由作者设置 0 至 `handraw_fixed_price_max` 的 5 分整数档，默认上限 100。
- 收费画风／图型采用系统动态价，默认初始 10、范围 5–30、每七天最多变化 5；样本、降价优先和投诉阈值沿用配置。
- 四类共享钱包、账本、幂等解锁和七天结算；默认作者 80%，平台回收 20%。收藏不影响解锁，关联资产分别购买。
- 新人一次性 10 分；三名有效用户认可奖励 3 分、作者每天最多三份；首次精选 20 分；免费画风／图型复用验证 30 分，与精选取高值补差。
- 收费内容须解锁且读取完整内容后才可评价。退款撤销权益和对应反馈的有效性；收入按原有账本追回。消费不减少作者的贡献记录与荣誉。

## 接口与个人库

- `/studio/api/assets`：按画风／图型和来源浏览，返回公开元数据。
- `/studio/api/assets/:ref` 与 `/related`：统一资产详情和关联作品、经验；官方引用为 `official:ID`，社区为 `community:UUID`。
- `/studio/api/entries` 与 `PATCH /entries/:id`：公共资料、私有 content 和关联 assets 分开提交；作者更新固定价会递增价格版本。
- `/entries/:id/content`、`/assets/:ref/content`：鉴权取得完整正文或定义；结构化资源带 SHA256。禁止公共缓存。
- `/creation/resolve`：服务端检查资产资格，解析完整定义并生成实际提示词；前端不能直接指定收费定义或将未经解析的文本发送号池。
- 个人库客户端按需同步 JSON 定义，校验后离线保存。已有 ZIP 离线命令继续兼容；新交易不要求 ZIP。官方编号库、用户本地内容均不被覆盖。

## 创作与生图

普通模式最多一个画风、一个图型；显式开启融合后使用角色画风和场景画风，且不得相同。指令通过原拼装器生成；实际融合提示词包含当前 Skill 的完整共存控制文本，版本化保存在 `plugin/content/fusion-prompt.txt`。不引入主辅权重或等权混合。

所有已验证、未被限制的用户每天最多成功生成五张，同时一个任务。按北京时间提交日预占次数，明确失败只归还一次，未确认的超时保留原任务。旧生成记录按北京时间归入相应提交日，保留私人历史。

生图走本机 `127.0.0.1:8000` 的异步任务接口，由现有号池调度账号。密钥仍在 Git 与公共目录之外；浏览器只能读取本人生成结果。此阶段无现金支付，也不扣社区积分。

## 验收与发布

自动化测试只使用隔离数据库 `handraw_web_test`。预览账户和示例只存在于 `handraw_web_preview`，禁发邮件，入口经 SSH 隧道暴露给本机。生产保留真实内容，不添加虚构作者、交易或互动。通过 CI 后部署指定提交，先备份，再执行增量迁移与健康检查；回滚代码不降级数据库。
